# 论文写作技能 · Research Paper Writing

这是一个用于规划、撰写和修订英文学术论文的 Codex 技能，也适合将中文研究笔记转成英文论文草稿。

- 从研究问题出发，把研究设计、分析、证据、主要发现、解释和适用范围对应起来。
- 按章节选择写作动作与英文表达，覆盖摘要、引言、文献综述、方法、结果、讨论和结论。
- 核对论断与数据、引文是否一致，检查因果措辞、过度外推和待核实的信息。介绍期刊文献时记录期刊、带年份的影响因子和带版本的中科院分区。

使用时可以让 Codex 读取 [SKILL.md](SKILL.md)，并提供研究问题、目标章节以及已有的材料。入口会指向 [四份参考资料](references/)，其中包含写作框架、原创英文示例和校稿检查项。

写作框架参考 [Sacred Heart University 图书馆指南](https://library.sacredheart.edu/organizing-research-papers/intro) 和 [USC 图书馆指南](https://libguides.usc.edu/writingguide)。英文表达按写作功能梳理，参考 [曼彻斯特大学 Academic Phrasebank](https://www.phrasebank.manchester.ac.uk/)。
